# 契约（对接 docs/01 模块划分）

# 模型结构（数据流定义）
整体：`input_ids (B,T)` → embedding `(B,T,768)` → 12×Block → 末层 RMSNorm → lm_head → `logits (B,T,32000)`；lm_head 与 embedding 共享权重。

Block（pre-norm，残差绕过子层）：
```
x = x + Attention(RMSNorm(x))
x = x + MLP(RMSNorm(x))
```

Attention（MHA，12 头 × 64 维）：
- q/k/v：各自 `Linear(768→768)`，reshape `(B,T,12,64)` 后转置为 `(B,12,T,64)`
- RoPE 仅施加于 q/k（v 不旋转）：rotate_half 约定——64 维拆两半 (x1,x2)，逐位置旋转 `x1'=x1·cos−x2·sin`，`x2'=x1·sin+x2·cos`；cos/sin 表按 max_seq_len 预计算
- 注意力：`F.scaled_dot_product_attention(q,k,v,is_causal=True)`，输出 `(B,12,T,64)` concat 回 `(B,T,768)`，过 `o_proj(768→768)`

MLP（SwiGLU，三个无 bias Linear）：
`down(silu(gate(x)) * up(x))`，gate/up `768→2048`，down `2048→768`

# 架构要点
- 前置 RMSNorm（pre-norm），最后接一个 RMSNorm 再出 logits
- RoPE 旋转位置编码，作用于 q/k；cos/sin 表按 max_seq_len 预计算
- SwiGLU：`down(silu(gate(x)) * up(x))`
- 因果注意力：上三角 mask；实现上优先用 `F.scaled_dot_product_attention(is_causal=True)`（跨平台 MPS/CUDA 均可跑）
- 权重初始化：Linear/Embedding `normal_(0, 0.02)`，各层 down/o 投影按 `0.02/sqrt(2·n_layers)` 缩放（GPT-2/Llama 教学惯例）

# 接口使用约定（下游模块对接须知）
最小用法：
```python
from src.model import LlamaModel, ModelConfig
model = LlamaModel(ModelConfig())          # ~109.5M 参数
logits = model(input_ids)                  # (B,T) long → (B,T,32000) float
```
- **forward 单参数**：模型不内置 loss、不支持 padding mask、无 KV cache；预训练的 next-token loss、SFT 的"只算回答部分"mask 均由外部数据/训练侧计算
- **超长即报错**：`T > max_seq_len(1024)` 抛 `ValueError`，数据侧必须自行截断/分块
- **ckpt**：RoPE cos/sin 是 non-persistent buffer，不进 `state_dict`，保存/加载权重无需处理；buffer 随 `.to(device)` 自动移动
- **train/eval 行为一致**：模型无 dropout，两模式仅影响梯度记录
- **跨平台**：MPS（M2）已实测通过；CUDA 未实测，但仅用 `F.scaled_dot_product_attention` 等标准算子，预期可直接跑（4070 上首次运行前建议先跑冒烟测试）

# 冒烟测试
- 参数量断言：≈1.095e8（允许 ±1%）
- 形状契约：随机 `input_ids (2, 16)` → logits `(2, 16, 32000)`，无 NaN
- 因果性：改第 t 位输入，t 之前位置的 logits 不变
- 反向传播：`logits.sum().backward()` 全参数有梯度
