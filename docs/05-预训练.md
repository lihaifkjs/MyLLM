# 05 预训练
> 模块4专题。输入契约（来自 docs/01）：`data/skypile_corpus.txt` + `tokenizer/` + `src/model/`；
> 输出契约：`pretrain.ckpt` + loss 曲线日志。

# 目标
next-token 预测全量语料 1 epoch，产出可用的预训练权重与 loss/ppl 曲线日志。

# 数据管线（离线 memmap）
1. `encode_corpus.py`：逐行读 `data/skypile_corpus.txt`，调 tokenizer encode，段间拼 `eos_id`（从 tokenizer 接口查询，不硬编码），全量写成 uint16 numpy memmap `data/clean/tokens.bin`（词表 32k < 65536，uint16 够用）。
2. 切分：末尾连续 1% token 作为验证集（`tokens_val.bin` 视角，同文件切片即可），其余为训练集。
3. `dataset.py`：训练时对 memmap 随机取起点，切 `ctx+1`（1025）个 token，`x=t[:-1], y=t[1:]`；验证集固定顺序切不重叠窗口，保证 ppl 可复现。

# 训练配置（默认值）
| 项 | 值 |
|---|---|
| 上下文 | 1024（与模型契约一致） |
| tokens/step | ~25万（CUDA: micro_batch 16 × grad_accum 16 × 1024 = 262,144；MPS 冒烟可调小） |
| 优化器 | AdamW，β(0.9, 0.95)，weight_decay 0.1（仅 2D 权重，norm/bias/embedding 不衰减） |
| lr | 峰值 6e-4，cosine 衰减到 3e-5，warmup = max(100, 2% total_steps) |
| total_steps | 由 token 总数 ÷ tokens/step 在运行时推出（1 epoch） |
| 梯度裁剪 | 1.0 |
| 精度 | CUDA→bf16 autocast；MPS/CPU→fp32（M2 冒烟用） |
| 设备 | 自动选择 cuda > mps > cpu，可命令行覆盖 |
| seed | 42 |

# 日志与产物
- `logs/pretrain_log.jsonl`：每 `log_interval` 步记训练 loss（滑动平均）、lr、tokens_seen、耗时；每 `eval_interval` 步记 val_loss、val_ppl。字段：`{"step": int, "type": "train"|"eval", ...}`。
- `checkpoints/pretrain_last.ckpt`：每 `save_interval` 步保存 `{model, optimizer, step, config}`，支持断点续训（`--resume`）。
- `checkpoints/pretrain.ckpt`：训练结束时的最终权重（同结构）。
- `plot_curve.py`：读 jsonl 用 matplotlib 画 train/val loss 与 ppl 曲线，输出 `logs/pretrain_curve.png`。

# 可观测性
- **实时进度**：tqdm 进度条显示 `step/total、ETA、loss(滑动平均)、lr、tokens/s`；中断（Ctrl-C）时先存 ckpt 再退出。
- **tensorboard（可选）**：检测到已安装则同步写 `logs/tb/` event 文件，未安装自动跳过；jsonl 仍是主数据源。
- **启动自检**：tokens.bin 存在且 token 数 ≥ 1 epoch 所需、ckpt/log 目录可写、打印实际设备与 dtype；前置缺失时报具体错因（如“请先运行 encode_corpus.py”）。
- **NaN/Inf 守卫**：跳过该 batch 并计数，连续 5 次中断并报“疑似梯度爆炸，建议降 lr 或从最近 ckpt 续训”。
- **grad_norm**：每步记录到 jsonl，用于判断梯度爆炸/裁剪是否生效。
- **loss spike 告警**：当前 loss > 滑动均值 ×2 时 stdout 打 warning（提示疑似脏数据段）。
- **CUDA OOM**：捕获后给出明确建议（调小 micro_batch 或加大 grad_accum）。

# 文件结构
- `src/pretrain/encode_corpus.py`：txt → tokens.bin
- `src/pretrain/dataset.py`：memmap 随机窗口采样
- `src/pretrain/train.py`：训练主循环（含 eval、ckpt、续训、可观测性）
- `src/pretrain/plot_curve.py`：loss/ppl 曲线
- `tests/test_pretrain.py`：冒烟测试——合成小 tokens.bin，CPU 跑数步，校验 ckpt 与日志契约
